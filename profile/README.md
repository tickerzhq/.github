Tickerz turns data into numbers markets can be built on. Each number is kept as first published, with a Bitcoin timestamp nobody can change. Tickerz publishes the number. It never runs the market.

**[Indexes](https://tickerz.com/x)** · **[Terminal](https://tickerz.com/terminal)** · **[Oracle](https://oracle.tickerz.com)** · **[Research](https://tickerz.com/research)** · **[API](https://tickerz.com/docs)**

### Open source

- **[tickerz-open](https://github.com/tickerzhq/tickerz-open)**: recount any signed Tickerz number from its source and check its Bitcoin proof yourself.
- **[typeshi](https://github.com/tickerzhq/typeshi)**: lock in fn. A slang language over Rust that compiles to real Solana programs.

### Plug it into your agent

```sh
claude mcp add --transport http tickerz https://tickerz.com/mcp
```

No key. Every index, its next likely number and its proof, from any MCP client. More at [tickerz.com/connect](https://tickerz.com/connect).
