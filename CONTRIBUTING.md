# Contributing

Thanks for helping. Each repository's README says how to run it and what help is most useful there.

- Open an issue before a large change, so nobody builds something that can't be merged.
- Keep pull requests small, and say what changed and why.
- Never put secrets, keys or personal data in code, issues or pull requests.
- Security problems go to desk@tickerz.com, not to a public issue. See SECURITY.md.

By contributing, you agree that your contribution is licensed under the licence of the repository you contribute to.
