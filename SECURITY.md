# Security

Report a security problem in any Tickerz repository, tickerz.com or the oracle to **desk@tickerz.com** with "security" in the subject. Please do not open a public issue for it.

Include what you found, where, and how to reproduce it. You get a reply within three working days, and a fix or a plan within fourteen. We credit reporters who want it once the fix ships. There is no paid bounty.

In scope: tickerz.com and its subdomains, the public API and MCP server, the signed numbers and their proofs, and the code in this organization. Out of scope: denial of service, social engineering, and reports from automated scanners with no working example.

The site's contact file: https://tickerz.com/.well-known/security.txt
